# ClearMind

Projeto desenvolvido usando .NET e React para ajudar pessoas com suas questões pessoais envolvendo emoções, usando integração com a inteligência artificial Gemini da Google.

A ideia principal do projeto é que o usuário possa informar o que está sentindo e a plataforma vai ajudá-lo a compreender o problema dando possíveis soluções que ele possa escolher seguir.
